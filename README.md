## À propos 

**Spinova** est une boutique en ligne spécialisée dans la vente directe de toupies de combat innovantes à lévitation magnétique, d'arènes, de lanceurs et de pièces détachées personnalisables.

Ce projet est développé dans le cadre de la SAÉ S3 à l'IUT de Blagnac. Il combine une architecture **PHP 8 MVC (Front Office & Back Office Admin)**, une base de données **MySQL** avancée (avec procédures stockées, triggers et scripts Faker), ainsi qu'une démarche stricte d'**accessibilité numérique (RGAA / lecteurs d'écran / forts contrastes)**.
